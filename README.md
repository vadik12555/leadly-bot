# Leadly — @Lead1HuntBot

Telegram-бот для поиска клиентов фрилансерам и студиям. Весь продукт работает внутри Telegram.

```
услуга → ниша → город → фильтры → компании из открытых источников → проверка сайта
      → гипотеза (на фактах) → 3 варианта первого сообщения → «Мои лиды» (мини-CRM)
```

Принципы: данные только из реальных источников. Чего нет в источнике, то показывается как «не найдено в источнике», а не как факт о компании. Гипотезы помечены как гипотезы. Бот никому не пишет сам.

## Быстрый старт

```bash
pip install -r requirements.txt
cp .env.example .env          # впиши BOT_TOKEN и ADMIN_IDS (на Windows: двойной щелчок по start-windows.bat)
python -m leadly              # long polling
```

Пошаговая инструкция владельцу (токен, оплата Stars, ключи ИИ, сервер): **[docs/OWNER_GUIDE.md](docs/OWNER_GUIDE.md)**.

Проверка без Telegram:

```bash
python -m leadly.devtools.console --demo   # чат с ботом в терминале (номер — кнопка, текст — сообщение)
pip install pytest pytest-asyncio && pytest  # 75 тестов: сценарии через настоящие Telegram-апдейты
```

## База компаний

Покупатели получают компании из своей базы бота (таблица `geo_cache`, ключи `companies:…`), а не напрямую с публичных серверов Overpass: они часто перегружены. В базе 60 городов России, 17 из них на кнопках, остальные вводятся через «Другой город».

Обновление раз в месяц (нужно `pip install osmium`, бот можно не останавливать):

1. Скачай `.osm.pbf` нужных округов с https://download.geofabrik.de/russia.html в `data/osm`.
2. Запусти `python -m leadly.devtools.import_osm data/osm`. Города не с кнопок перечисли после папки, иначе останутся старые данные.
3. Удали скачанные файлы.

Фоновый сборщик дополнительно обновляет города с кнопок через Overpass, когда серверы отвечают.

## Архитектура

```
leadly/
  bot/                     Telegram-слой (aiogram 3)
    app.py                 сборка, логирование с маскировкой токенов, напоминания, long polling
    handlers/              start · search · company (карточка, предложения, CRM) · billing (Stars)
                           · cabinet (статистика, рефералы) · admin · fallback
    views/                 экраны: (текст, клавиатура), без I/O
    storage.py             FSM в SQLite — незавершённый сценарий переживает перезапуск
  services/                бизнес-логика, не знает о Telegram
    search.py              лимиты → источники (по городам) → фильтры → сохранённая выдача
    leads.py               карточка, проверка сайта, ИИ, предложения, CRM, экспорт
    site_check.py          безопасная загрузка главной страницы, только наблюдаемые факты
    insights.py            факты → «не проверено» → гипотезы с уровнем уверенности
    writer.py              шаблоны предложений без ИИ (только подтверждённые факты)
    usage.py               лимиты с идемпотентными ключами
    billing.py             подписки и платежи Stars
    account.py             статистика, рефералы, админ-сводка
  providers/
    search/                SearchProvider: osm · twogis · demo + агрегатор с дедупликацией
    ai/                    AIProvider: none · anthropic · openai_compat
  db.py                    SQLite + миграции (PRAGMA user_version)
  config.py                .env + config/plans.json
config/plans.json          цены (Stars), лимиты, бонусы — меняются без кода (/admin → «Перечитать»)
deploy/                    systemd-юнит, install.sh, update.sh
```

Новый источник данных — класс-наследник `SearchProvider` с методом `search(query)`, плюс регистрация в `providers/search/__init__.py::build_search`. Новый ИИ-провайдер — наследник `AIProvider`.
