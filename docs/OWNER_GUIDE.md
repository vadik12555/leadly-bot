# Leadly: инструкция владельца

Здесь только то, что нужно сделать с твоей стороны. Секреты (токены, ключи) вписывай только в файл `.env` на сервере и никому их не присылай, в том числе в чат с разработчиком или ИИ.

---

## 1. Токен бота и твой ID (обязательно)

1. В Telegram открой **@BotFather** → `/mybots` → **@Lead1HuntBot** → **API Token** и скопируй токен.
2. Узнай свой числовой ID: напиши **@userinfobot**, он ответит числом вида `123456789`.
3. В `.env` впиши:
   ```
   BOT_TOKEN=токен_из_BotFather
   ADMIN_IDS=123456789
   SUPPORT_CONTACT=@твой_username
   ```

**Проверка:** после запуска напиши боту `/start`, потом `/admin`. Админка должна открыться только у тебя.

Если токен утёк: @BotFather → `/mybots` → бот → **API Token** → **Revoke**, затем впиши новый токен в `.env` и перезапусти бота.

## 2. Где запускать бота (чтобы работал без твоего компьютера)

### Подходит ли обычный хостинг Beget

На обычном **виртуальном хостинге** (тарифы для сайтов), как правило, нельзя держать постоянно работающий процесс, а бот должен работать круглосуточно. Я не могу проверить твой тариф: Beget недоступен из моей среды. Поэтому проверь сам:

- В панели Beget открой раздел с тарифом. Если там написано **VPS** или **VDS**, всё подходит, переходи к шагу 2.1.
- Если это «Хостинг сайтов» (Blog, Start, Noble и т.п.), это виртуальный хостинг. Спроси поддержку Beget: «Можно ли запустить постоянный фоновый процесс Python 3.10+ (Telegram-бот, long polling) 24/7?». Если ответ «нет», нужен VPS.

**Рекомендация:** самый маленький **VPS** (1 vCPU, 1 ГБ RAM, Ubuntu 24.04). Это может быть VPS Beget (раздел «VPS» в той же панели) или любого другого провайдера. Данные бота (SQLite) занимают мегабайты.

### 2.1. Установка на VPS

1. В панели VPS найди IP-адрес и пароль root. Подключись с компьютера (терминал Windows/Mac):
   ```
   ssh root@IP_СЕРВЕРА
   ```
2. Загрузи код. Лучший вариант — приватный GitHub-репозиторий:
   ```
   apt-get update && apt-get install -y git
   git clone https://github.com/ТВОЙ_АККАУНТ/leadly.git /opt/leadly
   ```
   Без GitHub: загрузи архив `scp leadly.zip root@IP:/root/` и распакуй его в `/opt/leadly`.
3. Установи:
   ```
   sudo bash /opt/leadly/deploy/install.sh
   nano /opt/leadly/.env        # впиши BOT_TOKEN, ADMIN_IDS, SUPPORT_CONTACT; Ctrl+O, Enter, Ctrl+X
   sudo systemctl restart leadly
   ```

### 2.2. Управление ботом

| Что | Команда |
|---|---|
| Состояние | `sudo systemctl status leadly` |
| Остановить / запустить | `sudo systemctl stop leadly` / `sudo systemctl start leadly` |
| Перезапустить | `sudo systemctl restart leadly` |
| Логи в реальном времени | `sudo journalctl -u leadly -f` |
| Только ошибки | `grep ERROR /opt/leadly/data/leadly.log \| tail -20` (или `/admin` → «Ошибки» прямо в Telegram) |
| Обновить код | `sudo bash /opt/leadly/deploy/update.sh` (перед обновлением делается бэкап базы) |
| Бэкап базы | скопируй `/opt/leadly/data/leadly.db` |

Бот сам перезапускается после падения или перезагрузки сервера.

### 2.3. Если в логе «Нет связи с api.telegram.org»

Это проблема сети сервера, а не кода:

1. Проверь доступ к Telegram: `curl -sI https://api.telegram.org | head -1`. Ответ `HTTP/2 302` или `200` значит, что Telegram доступен.
2. Если ответа нет, проблема в DNS, фаерволе или блокировке. Укажи прокси в `.env` (`TELEGRAM_PROXY=http://user:pass@host:port`) или возьми VPS в другой локации.

Бот не зацикливается: при старте он сразу пишет понятную ошибку, а systemd повторяет попытку раз в 10 секунд. Разрывы связи во время работы aiogram переживает сам, с нарастающей паузой до 60 секунд.

## 3. Источники данных

**OpenStreetMap** включён по умолчанию (`SEARCH_PROVIDERS=osm`): бесплатно и без ключа. Правила OSM просят указывать контакт: впиши свою почту в `OSM_CONTACT=`. Ограничения:

- малый бизнес в OSM представлен неполно, а в маленьких городах особенно;
- телефоны и сайты указаны не у всех.

Именно поэтому бот пишет «не найден в источнике», а не «нет сайта».

**Контакты с сайтов компаний.** Если в OSM у компании указан только сайт, бот при поиске сам открывает её сайт (главную и страницу «Контакты», с учётом robots.txt) и берёт оттуда телефон и почту. В карточке такие данные помечены «с сайта компании», а в выдаче видно, сколько компаний с контактами.

**Проверка:** найди «Салоны красоты» в «Казань». В выдаче должны быть реальные компании, а в карточке ссылка «Открыть в OpenStreetMap».

**2ГИС** (больше компаний и контактов, платно):

1. Зарегистрируйся на https://dev.2gis.com и запроси ключ к **Places API**. Сначала выдают демо-ключ, для работы нужен тариф. Контакты (телефоны, сайты) входят не во все тарифы, это нужно уточнить у 2ГИС.
2. Впиши в `.env`:
   ```
   TWOGIS_API_KEY=ключ
   SEARCH_PROVIDERS=osm,2gis
   ```
3. Перезапусти бота и проверь `/admin` → «Источники и ИИ»: напротив 2ГИС должно быть написано «ключ задан». Затем сделай поиск: в выдаче будет «OpenStreetMap + 2ГИС», дубликаты склеиваются автоматически.

Код 2ГИС проверен тестами на образцах ответов, но не на живом API. Если в первом поиске будет ошибка, посмотри `/admin` → «Ошибки».

**Яндекс и Google Places** не подключены. Их API платные, а в бесплатных условиях есть ограничения на хранение и показ данных вне их карт, которые плохо сочетаются с CRM. Подключать их стоит после того, как появятся платящие пользователи.

## 4. ИИ-анализ (по желанию)

Без ключа всё работает: бот честно пишет «ИИ-анализ пока не подключён» и делает предложения по шаблонам, опираясь только на проверенные факты.

**Вариант A — Claude (Anthropic):**

1. Получи ключ на https://console.anthropic.com → API Keys и пополни баланс.
2. Впиши в `.env`:
   ```
   AI_PROVIDER=anthropic
   ANTHROPIC_API_KEY=ключ
   ```
   По умолчанию используется модель `claude-opus-5-5`, её можно сменить через `ANTHROPIC_MODEL`.
3. Учти: из России доступ к API Anthropic может быть недоступен. Сервер должен быть в стране, где сервис работает.

**Вариант B — любой OpenAI-совместимый API** (DeepSeek, OpenRouter, совместимый эндпоинт YandexGPT, свой сервер):

```
AI_PROVIDER=openai_compat
OPENAI_COMPAT_BASE_URL=https://адрес-провайдера/v1
OPENAI_COMPAT_API_KEY=ключ
OPENAI_COMPAT_MODEL=название-модели
```

**Проверка:** `/admin` → «Источники и ИИ» должно показывать название провайдера. Затем открой компанию → «🤖 ИИ-анализ».

ИИ получает только публичные данные компании и проверенные факты. Телефоны, почта и данные пользователя ИИ-провайдеру не отправляются.

## 5. Оплата: Telegram Stars

**Почему Stars.** По правилам Telegram цифровые товары и услуги внутри ботов продаются за Telegram Stars (валюта `XTR`). Документация: https://core.telegram.org/bots/payments-stars. Внешний платёжный провайдер для этого не нужен.

**Что уже сделано в коде:**

- счёт выставляется прямо в Telegram;
- перед оплатой бот проверяет сумму, тариф и владельца счёта;
- тариф включается только после события `successful_payment` от Telegram;
- повторное событие не зачисляется дважды (защита по ID платежа);
- за 3 дня до окончания приходит напоминание, после окончания пользователь переходит на FREE;
- команда `/paysupport` (Telegram требует поддержку по оплатам) и `/terms` с условиями.

**Что сделать тебе:**

1. Цены в Stars задаются в `config/plans.json` (`price_stars`). Сейчас там PRO — 199 ⭐ и PRO+ — 549 ⭐. Это примерно 299 ₽ и 799 ₽ при покупке Stars, точный курс зависит от способа покупки. После правки нажми `/admin` → «Перечитать plans.json».
2. Впиши `SUPPORT_CONTACT` (см. шаг 1). Telegram требует, чтобы у платёжного бота была поддержка по оплатам.
3. Проведи тестовую покупку сам: `/plans` → «Оформить PRO» → оплати. Списываются настоящие Stars (199 ⭐). Чтобы вернуть их, найди ID платежа в `/user ТВОЙ_ID` и выполни `/refund ID`.
4. Вывод заработанных Stars делается в @BotFather → бот → **Balance** (через Fragment). Периоды удержания и комиссии смотри там же, условия меняются.

**Подписка с автопродлением.** В «⭐ Тарифы» у каждого платного тарифа две кнопки: подписка (Telegram сам списывает Stars каждые 30 дней) и разовая оплата на 30 дней. Пользователь может отключить автопродление кнопкой в «⭐ Тарифы»: доступ сохранится до конца оплаченного периода.

**Пробный период и промокоды.**
- Каждый пользователь один раз может включить PRO бесплатно на 3 дня. Настройка — блок `trial` в `config/plans.json`.
- Промокод создаётся командой `/promo КОД pro ДНЕЙ МАКС_АКТИВАЦИЙ`, например `/promo START30 pro 30 100`. Пользователь вводит его в «⭐ Тарифы» → «🎟 Ввести промокод».

**Ключи активации.** `/keys pro 30 10` выдаёт 10 одноразовых ключей вида `LDY-ABCD-EFGH` на PRO на 30 дней. Пользователь вводит ключ в «⭐ Тарифы» → «🎟 Промокод или ключ». `/keys` без параметров показывает, сколько ключей выпущено и активировано. Подходит для подарков, конкурсов в канале, партнёров и продаж по счёту от ИП или самозанятого.

⚠️ **Не пиши в боте «переведи деньги на карту — получи ключ».** По правилам Telegram цифровые товары внутри бота продаются за Stars, и за такую схему бот могут заблокировать. Переводы на личную карту без чеков — риск блокировки со стороны банка (115-ФЗ) и налоговый риск. Продавать ключи вне Telegram — твоё решение и твоя ответственность.

**Тариф на год.** У платных тарифов есть разовая покупка на 365 дней со скидкой: цена — `year_price_stars` в `config/plans.json`.

**Рассылка всем пользователям:** `/broadcast текст`. Бот покажет предпросмотр и попросит подтвердить. Пиши только по делу (новые функции, важные изменения): частые рассылки заставляют блокировать бота.

**Уведомления об ошибках.** Если в работе бота возникает ошибка, админам из `ADMIN_IDS` приходит сообщение в Telegram (не чаще раза в 2 минуты).

Для тестов без оплаты есть команда `/grant ID pro 7`. Она доступна только админу и выдаёт тариф вручную. Обычным пользователям тестовой «оплаты» нет.

Отключить оплату можно строкой `PAYMENTS_ENABLED=false`: кнопки покупки исчезнут.

## 6. Лимиты и тарифы

Все лимиты задаются в `config/plans.json`:

- **FREE:** 3 поиска, 45 компаний в выдаче, 30 открытий карточек, 10 проверок сайтов, 3 ИИ-анализа, 5 генераций предложений и 20 сохранённых лидов. Всё это лимиты за всё время, а не в день.
- **PRO и PRO+:** дневные лимиты.

`/start` лимиты не обнуляет. Повторное открытие той же карточки или повторное нажатие «Найти» с теми же параметрами лимит не тратит. Если источник или ИИ не ответил, лимит возвращается.

## 7. Твой канал

1. Впиши в `.env`: `CHANNEL_USERNAME=имя_канала` (без @).
2. Добавь бота **администратором** в канал (Канал → Управление → Администраторы → Добавить → @Lead1HuntBot; права можно не давать никакие). Без этого Telegram не позволит проверить подписку.
3. В главном меню появятся кнопки «📣 Наш канал» и «🎁 +2 поиска за подписку». Бонус выдаётся один раз и только после проверки подписки. Размер бонуса — `channel_bonus_searches` в `config/plans.json`.

## 8. Бэкапы

Бот каждый день сохраняет копию базы в `data/backups` (хранятся последние 7), а по понедельникам присылает файл админам в Telegram. Для восстановления: останови бота и замени `data/leadly.db` нужной копией.

## 9. Персональные данные

- В `.env` впиши `OPERATOR_NAME=` — кто оператор персональных данных (например, «ИП Иванов Иван Иванович, ИНН …» или ФИО самозанятого). Это имя показывается в `/privacy`.
- В боте есть `/privacy` (политика конфиденциальности) и `/delete_my_data`: пользователь сам удаляет свои данные. Записи об оплатах сохраняются как финансовые документы.
- Тексты — рабочий черновик, а не юридическая консультация. Перед масштабированием покажи их юристу и проверь, нужно ли уведомить Роскомнадзор об обработке персональных данных.

## 10. Нужен ли сайт

Для запуска сайт не обязателен. Он пригодится позже:

- как страница для доверия (описание, тарифы, FAQ, кнопка «Открыть в Telegram»);
- для публикации пользовательского соглашения и политики конфиденциальности. Бот хранит Telegram ID пользователей, а это персональные данные, поэтому политику стоит опубликовать до масштабирования.

Для оплаты в Stars отдельный сайт не требуется. Сайт можно разместить на обычном хостинге Beget: для статических страниц он подходит.
